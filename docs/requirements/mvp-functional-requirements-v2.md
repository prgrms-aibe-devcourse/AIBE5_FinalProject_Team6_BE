# FANDROPS MVP 기능 요구사항 명세서 (FRD)

본 문서는 K-Pop 팬덤 커머스 및 예약 플랫폼인 **FANDROPS**의 MVP(Minimum Viable Product) 단계에서 제공하는 핵심 기능 요구사항 명세서(SSOT)입니다.

## 0. 용어 (B2B · `AGENCY_*`)

DB·API 식별자(`AGENCY_ACCOUNT`, `agency_id`, `ROLE_AGENCY` 등)는 **변경하지 않는다**.  
**`AGENCY_*`는 법인 기획사만이 아니라, 아티스트 공간을 운영하는 B2B 주체(기획사·1인 크리에이터·매니저)** 를 가리킨다.  
화면·기능 설명에서는 **아티스트 스튜디오**, **운영 주체**, **운영자** 등 상위 개념을 쓴다. ([ERD §4](../erd/erd-design.md#4-agency_account--artist_profile--artist_member--fan))

## 2. 미결 및 연동 정책

1. **글로벌 알림의 연동**: `is_allow_notification`이 `false`인 유저는 `NOTIFICATION` 테이블에 수신 로그가 생성되더라도 외부 SMS/알림톡 등 써드파티 발송 파이프라인에서 필터링되어 실제 발송이 전면 차단됩니다.
2. **일정-공지 연동 시의 `GENERAL` 공지 처리**: 아티스트 스튜디오에서 일정 등록 시 `NOTICE` 카테고리 일정으로 동기화되며, 공지사항 등록 시 '일정 자동 연동' 스위치를 켜면 아티스트 캘린더에 일반 일정 형태로 즉각 세부 내용과 링크가 생성됩니다.
3. **입점 프로세스 무결성**: 미승인 상태의 운영 입점 신청 정크 데이터가 실제 `AGENCY_ACCOUNT` 로그인 계정 테이블을 오염시키는 것을 방지하기 위해 `AGENCY_APPLICATION` 입점 신청서 물리 테이블을 분리 운영한다. Admin 승인(`APPROVED`) 시점에 한 트랜잭션으로 `AGENCY_APPLICATION` ↔ `AGENCY_ACCOUNT` 1:1 결합과 **`ARTIST_PROFILE` 아티스트 공간**(`target_artist_name` 반영)이 연쇄 생성된다 (F02-02 · [ERD §4](../erd/erd-design.md#4-agency_account--artist_profile--artist_member--fan) · [state §7.4](../state/invariants-and-state-machines.md#74-b2b-운영-입점-신청-agency_application)).
