## 도메인 오너십 (F-scope)

| 담당 | F-ID |
| --- | --- |
| 표지민 | F01-01~03, F02-01~02, F03-04(전송), F08-02(입점 연동) |
| 정환철 | F01-04, F02-03, F03-01~08, F05-01~03, F04-03(메인 배너), F07-01 |
| 형성빈 | F04-01~02, F04-04~05, F07-02(주문) |
| 장성재 | F04-02(오픈·대기열), F06-01~03, F07-02(결제), 대기열·RateLimit |
| 지영재 | F08-02(플랫폼·관측·부하) |

> **F01-04**는 F01 그룹이나 HTTP 구현은 `community`(팬–아티스트 관계). Auth는 `user`.

## MVP에 없는 기능 (본 표 미등재)

- 고객센터 FAQ·1:1 문의
- 신고·제재 Admin
- 인앱 콘서트 좌석 예매·복수 PG
- 실시간 채팅, 자체 영상 호스팅, 추천/Elasticsearch
- 오프라인 ERP 실시간 재고 연동
